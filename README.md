# Website-Groundwork | Naka Studio

An open gallery and comprehensive documentation repository dedicated to my frontend design works and backend system experiments. Everything stored here is fully viewable, accessible, and ready to be cloned under the **MIT License**.

---

## Repository Structure

To maintain a clean organization, this repository is split into three main branches based on the scope of development:

*   **`main`**: The primary branch containing the main documentation, overview, and general guidelines (where you are right now).
*   **`front-end`**: Dedicated to frontend design galleries and source code. This branch is further categorized by project types and industries, including:
    *   *Personal Portfolios*
    *   *Cafe & Restaurant Landing Pages*
    *   *Real Estate Platforms*
    *   *E-commerce & Marketplaces*
    *   *And more.*
*   **`backend`**: Houses a collection of lightweight, simple API projects. These can be used publicly as mock servers, testing endpoints, or learning resources for anyone interested.

---

## How to Clone & Switch Branches

If you want to clone this repository locally to inspect, test, or build upon the projects, follow the steps below.

### 1. Clone the Repository
Open your terminal or command prompt and run the following command:

```bash
git clone https://github.com/Naka-studio/Website-Groundwork.git
```

### 2. Navigate into the Project Directory
```bash
cd Website-Groundwork
```

### 3. Switch Between Branches
Since the projects are isolated into different branches, use `git checkout` or `git switch` to access the specific area you want to explore:

*   **To view Front-End projects:**
    ```bash
    git checkout front-end
    ```
*   **To view Back-End projects:**
    ```bash
    git checkout backend
    ```
*   **To return to the main documentation:**
    ```bash
    git checkout main
    ```
